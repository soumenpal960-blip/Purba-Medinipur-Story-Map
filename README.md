# Purba Medinipur Story Map

Interactive coastal, heritage, river-port and food story map of Purba Medinipur, West Bengal.

Features:
- Beaches and coastal destinations
- Heritage and temple sites
- River and port locations
- Restaurants in Contai / Kanthi and Digha
- Real/context photo galleries with satellite fallback
- Search and category filter
- Normal and satellite maps
- My Location, route distance, estimated time and Google Maps navigation

Created by **Soumen Pal** — Remote Sensing & GIS.
